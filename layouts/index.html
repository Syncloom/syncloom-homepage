How it works

From zero to syncing in three steps

  1. 1

    Run the server

    One docker compose up gives you the server, the web app, Postgres and HTTPS. It needs about 200 MB of RAM.

  2. 2

    Create your vault

    Pick a password. Your device derives the encryption keys and shows you a recovery key, once. The server never sees any of it.

  3. 3

    Install the apps

    Sign in on your Mac, phone, Linux box or browser. Add a security key as a spare, and your files follow you everywhere.

Security

Zero knowledge is not a slogan here

Your password never leaves your device. It is stretched with Argon2id into a login secret for the server and a key that unlocks your vault. They are different, so the server cannot derive your keys.

  • {{ partial "icon.html" (dict "name" "check" "size" 18) }} Per-file keys wrapped under per-folder keys, wrapped under your master key
  • {{ partial "icon.html" (dict "name" "check" "size" 18) }} Sharing wraps keys to the recipient's public key (X25519)
  • {{ partial "icon.html" (dict "name" "check" "size" 18) }} Public link keys live in the URL fragment, never in a request
  • {{ partial "icon.html" (dict "name" "check" "size" 18) }} Mandatory second factor, brute-force protection, replay-safe codes
